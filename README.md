# 명탐정 몽타주

초등 2학년 2학기 국어 3단원(설명하는 글) 수업용 웹 게임이에요. 말과 글로 정확하게 설명해서 우주 정거장의 도둑을 찾아요.

## 활동
- **도둑 찾기 게임 (1차시)**: 설명자가 비밀 캐릭터를 말로 설명하면 탐정이 돌아다니는 후보 중에서 도둑을 찾아요.
  - 역할: 설명자 / 탐정 / 자동 교대(1인 1태블릿, 라운드마다 설명자가 번호 순서로 바뀜) / 둘 다 보기(시연)
  - 후보 소거 → `범인 지목!`(5초 선택) 또는 마지막 1마리 자동 지목 → 결과 화면에서 정답 공개와 특징 되짚기
  - 변장 모드, 듣기 단계, 제한 시간, 총 라운드, 움직임·뒤돌기·사라지기 빈도 설정
- **현상수배서 (2차시)**: 비밀 캐릭터를 보고 현상수배서를 쓴 뒤 태블릿을 친구에게 넘기면, 친구가 글만 읽고 라인업에서 도둑을 찾아요. 종이에 쓴 글로 찾기만 할 수도 있어요.
- **점수판 (교사용)**: 팀별 라운드 점수(맞춘 탐정 수 ÷ 탐정 수)를 입력하면 총점과 순위를 계산해요. 동점이면 평균 시간이 짧은 팀이 이겨요.

같은 모둠 번호와 라운드를 넣으면 어느 기기에서나 같은 도둑이 나와요. 서버가 필요 없고, `index.html` 파일 하나로 동작해요.

## 배포 (GitHub Pages)
1. GitHub에 빈 공개 저장소를 만들어요.
2. 저장소 Settings → Pages → Source를 `GitHub Actions`로 바꿔요.
3. 이 폴더를 저장소에 올리면(`main` 브랜치) 자동으로 배포돼요.
