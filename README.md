# 명탐정 몽타주

초등 2학년 2학기 국어 3단원(설명하는 글) 수업용 웹 게임이에요. 말과 글로 정확하게 설명해서 우주 정거장의 도둑을 찾아요.

## 활동
- **도둑 찾기 게임 (1차시)**: 설명자가 비밀 캐릭터를 말로 설명하면 탐정이 돌아다니는 후보 중에서 도둑을 찾아요.
  - 역할: 설명자 / 탐정 / 자동 교대(1인 1태블릿, 라운드마다 설명자가 번호 순서로 바뀜) / 둘 다 보기(시연)
  - 후보 소거 → `범인 지목!`(5초 선택) 또는 마지막 1마리 자동 지목 → 결과 화면에서 정답 공개와 특징 되짚기
  - 변장 모드, 듣기 단계, 제한 시간, 총 라운드, 움직임·뒤돌기·사라지기 빈도 설정
- **현상수배서 (2차시)**: 비밀 캐릭터를 보고 현상수배서를 쓴 뒤 태블릿을 친구에게 넘기면, 친구가 글만 읽고 라인업에서 도둑을 찾아요. 종이에 쓴 글로 찾기만 할 수도 있어요.
- **점수판 (교사용)**: 팀별 라운드 점수(맞춘 탐정 수 ÷ 탐정 수)를 입력하면 총점과 순위를 계산해요. 동점이면 평균 시간이 짧은 팀이 이겨요.

- **온라인 반 대결 (Firebase)**: 교사는 `선생님 / 다른 활동 → 온라인 반 대결 → 온라인 반 열기`(또는 주소 끝에 `?teacher`)로 숫자 4자리 반 코드와 QR을 만들어요. 학생은 사이트 첫 화면에서 **반 코드 → 팀 색깔 → 내 번호**만 누르면 들어와요(QR로 열면 반 코드도 생략, 두 번째부터는 `지난번처럼 들어가기` 한 번). 교사가 라운드를 시작하면 모든 태블릿이 함께 넘어가고, 설명자는 팀 안에서 번호 순서대로 자동 교대돼요. 변장과 `설명 끝`은 팀 안에서 자동으로 맞춰지고, 점수는 자동으로 모여요.

같은 모둠 번호와 라운드를 넣으면 어느 기기에서나 같은 도둑이 나와요. 서버가 필요 없고, `index.html` 파일 하나로 동작해요.

## Firebase 연결 (온라인 반 대결용)
1. https://console.firebase.google.com 에서 프로젝트를 만들어요(애널리틱스는 꺼도 돼요).
2. 빌드 → Realtime Database → 데이터베이스 만들기 → 위치는 `asia-southeast1`(싱가포르) → **잠금 모드**로 시작.
3. Realtime Database의 `규칙` 탭에 [database.rules.json](database.rules.json) 내용을 붙여 넣고 게시해요.
4. 프로젝트 설정(톱니바퀴) → 내 앱 → 웹(`</>`) 앱을 등록하고, 나오는 `firebaseConfig` 값을 `index.html`의 `FIREBASE_CONFIG`에 넣어요.

학생 이름 같은 개인정보는 저장하지 않고 반 코드·팀 번호·번호·정답 여부·걸린 시간만 저장해요.

## 배포 (GitHub Pages)
1. GitHub에 빈 공개 저장소를 만들어요.
2. 저장소 Settings → Pages → Source를 `GitHub Actions`로 바꿔요.
3. 이 폴더를 저장소에 올리면(`main` 브랜치) 자동으로 배포돼요.
